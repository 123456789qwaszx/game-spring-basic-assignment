# M6. 이름 변경과 삭제

## 목표

PATCH·DELETE로 변경 감지와 자식 삭제를 확인한다.

## 이번 단계에서 이해할 것

변경 감지, FK 관계, 삭제 순서

## 구현 순서

- [o] RenameRequest에 이름 공백 금지·2~12자 검증을 작성한다.
- [o] PATCH는 쓰기 트랜잭션에서 조회 → game.rename → 204. 불필요한 save 없이 DB 반영을 확인한다.
- [ ] DELETE는 쓰기 트랜잭션에서 게임 조회 → 해당 RunCard 삭제 → Game 삭제 → 204로 작성한다.
- [ ] 없는 게임은 404. 이름 변경은 다른 진행 필드와 카드 ID를 바꾸지 않는다.

- [ ] 왜 자식부터 삭제하는가?
- [ ] 다른 게임이 유지됨을 어떻게 확인했는가?
