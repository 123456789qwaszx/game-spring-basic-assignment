# Crimson Citadel — 전체 PLAN v3

> Java·Spring 1주 차 / C#·Unity 경험자 / 4일 핵심 학습 프로젝트
> 구현: Lv 1~8. 자체 제출 목표 2026-09-11 17:00 KST, 공식 마감 20:00.
> 상태: 계획 작성. 구현·실행 검증은 아직 완료 처리하지 않음.

## 1. 목적과 범위

게임 체크포인트와 덱을 저장·조회하는 여섯 API를 직접 작성한다.
 **DI·3 Layer / DTO·Validation / 트랜잭션 / JPA 변경 감지 / 단방향 관계·삭제**를 코드와 실행으로 설명하는 것이 학습 목표다.

필수는 Docker MySQL·JPA·DTO·검증·6개 API·실행 확인·문서·제출이다.
 Lv 9·10의 종료 상태 409·전용 예외 확장, Lv 11 집계·시간, 랭킹·검색·인증·배포는 이번 기준 일정에서 제외한다.
