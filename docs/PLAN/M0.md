# M0. 환경과 실행 기반

## 목표

Docker MySQL 연결과 애플리케이션 부팅을 확인한다.

## 이번 단계에서 이해할 것

설정, Bean 등록, 생성자 주입

## 시작 조건

기존 파일·static·Gradle 설정을 보존하고 작업 브랜치를 확인한다.

## 구현 순서

- [ ] JDK 21과 Gradle wrapper 실행을 확인한다.
- [ ] Docker MySQL의 포트·DB·계정·volume을 정하고 연결을 확인한다.
- [ ] application.properties에 datasource·개발용 ddl-auto=update·show-sql·open-in-view=false를 설정한다. 실제 비밀번호는 환경 변수로 전달한다.
- [ ] 기존 클래스와 패키지를 유지하고 @Service·생성자 주입을 정상 연결한다.
- [ ] 기존 Entity를 보존한 상태에서 부팅한다. 정적 HTML 제공과 게임 타이틀 정상 동작은 구분한다.
