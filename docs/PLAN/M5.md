# M5. 게임 목록과 이어하기

## 목표

GET /games와 게임의 저장된 여정 화면을 연결한다.

## 이번 단계에서 이해할 것

정렬 조회, 요약 DTO, 이어하기

## 시작 조건

M4의 결과와 남은 문제를 확인한다. 선행 실행 기반이 막히면 독립 작업만 진행하고 완료 판정을 미룬다.

## 구현 순서

- [ ] GameRepository.findAllByOrderByIdDesc를 작성한다.
- [ ] GameSummaryResponse에 기본 게임 필드를 담고 deck은 제외한다.
- [ ] GET /games를 실제 Repository 조회까지 연결한다. DB가 비었을 때만 빈 배열이 나온다.
- [ ] 조회 서비스에 readOnly 트랜잭션을 적용한다.
- [ ] 실제 게임에서 생성·진행·새로고침·여정 선택을 함께 확인한다.
